
# Open Creative Toolkit

An open-source toolkit for AI-assisted animation, video creation, and creative automation.

## Mission

Make creative production accessible through free and open-source software, reusable workflows, and developer-friendly tools.

## Project Goals

- Build accessible 2D animation workflows.
- Explore automated video composition.
- Integrate open-source animation technologies.
- Create reusable creative production tools.
- Document workflows for beginners and developers.

## Planned Technologies

- HyperFrames — video composition
- GSAP — web animation
- JavaScript — automation and tooling
- HTML and CSS — creative interfaces

## Development Status

Early development — Foundation stage.

Features will be added, tested, and documented as development progresses.
